# Screen Audio Hotkey

Утилита для Windows, которая записывает звук устройства воспроизведения по горячей клавише. Подходит, когда нужно быстро сохранить системный звук в WAV.

## Запуск

Установите .NET 8 SDK и выполните из папки проекта:

```powershell
dotnet run
```

После запуска появится значок в области уведомлений. Нажмите **Ctrl+Shift+R**, чтобы начать запись. Нажмите ещё раз, чтобы завершить её и сохранить файл. Эти же действия доступны в меню значка.

Записи сохраняются в папку **Видео → ScreenAudioHotkey** с датой и временем в имени. Папку можно открыть из меню приложения. Запись идёт через WASAPI loopback и захватывает звук воспроизведения. Для сборки используйте `dotnet build -c Release`.

Если горячая клавиша занята, освободите её в другой программе перед запуском.
